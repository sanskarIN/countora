# GitHub repository operations

Recommended repository settings:

- protect `main`
- require pull requests for non-emergency changes
- require the `CI / flutter` status check
- require branches to be up to date before merge
- enable Dependabot alerts and security updates
- enable secret scanning and push protection when available
- enable Discussions for usage questions and ideas
- use squash merge for most feature pull requests

Suggested labels:

- `bug`
- `enhancement`
- `documentation`
- `accessibility`
- `security`
- `performance`
- `platform: android`
- `platform: ios`
- `platform: web`
- `platform: desktop`

Use milestones for `0.2`, `1.0`, and later release goals.
