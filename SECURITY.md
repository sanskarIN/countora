# Security Policy

## Reporting a vulnerability

Please do not publish a security-sensitive issue before a fix is available.

Report suspected vulnerabilities to:

- `sanskarin@outlook.in`
- `supportramsandesh@gmail.com`

Include affected version, platform, reproduction steps, impact, and the minimum safe detail needed to reproduce the defect.

## Scope

Countora is local-first. Security review focuses on local state integrity, import validation, notification permissions, dependency integrity, secret scanning, and safe link handling.

Never include real credentials, signing secrets, private user backups, or sensitive personal information in a report.
